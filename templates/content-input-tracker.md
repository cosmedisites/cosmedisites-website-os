# 13. Content / Input Tracker

**Owner:** Content Lead / Project Lead
**Approval:** Internal unless stated

## Purpose
Give every required production input an owner, status and deadline so build is never blocked by vague missing information.

## Typical inputs

| Field | Entry |
|---|---|
| Practitioners | Roles, titles, registrations, qualifications, expertise, awards. |
| Treatments | Current treatment list, prices, course, downtime, who provides each. |
| Reviews | Google / platform access, source URLs. |
| Photography | Shoot date, existing assets, patient consent. |
| Business details | Locations, hours, phone, booking links, consultation status. |
| Brand files | Vector logos, brand assets. |
| Compliance | Required disclaimers / policy constraints. |

## Definition of Done

- [ ] Every required input has an owner.
- [ ] Every input has a status.
- [ ] Pending items have a deadline.
- [ ] Received information is verified before publication.
