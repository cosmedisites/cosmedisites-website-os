# CosmediSites Website Redesign Template Pack v1.0

This pack is the operational layer beneath the CosmediSites Website Strategy Playbook.

Use it as:
- **Playbook** = how we think.
- **SOP** = what happens next, who owns it, and when it is done.
- **Templates** = the artefacts used to execute the process.

## Operating rule
Never move to the next stage because the previous one feels approximately finished.
Move when its **Definition of Done** has been met.

## Decision hierarchy
1. Business strategy
2. Positioning
3. UX / information architecture
4. Content / proof
5. Visual expression

Lower-level preference should not casually overturn a higher-level strategic decision.

## Using these templates in the Website OS

*(Added in the repository; the text above is the Template Pack v1.0 README, unchanged.)*

- **Never fill a template in inside this repository.** Copy it into the client's Drive folder
  (Google Doc) and complete it there. Filled templates are client data (see `SECURITY.md`).
- File naming (Deployment Guide): `CLIENT_Artefact_v0.X_WORKING_YYYY-MM-DD` →
  `CLIENT_Artefact_v1.0_APPROVED_YYYY-MM-DD`.
- If an artefact genuinely does not apply to a smaller project, mark it **N/A** rather than silently
  skipping it (SOP, Mandatory Project Artefacts).
- The tabular artefacts (09 Proof Inventory, 12 Approval Record decision log, 13 Content / Input
  Tracker, 15 QA, 16/17 Measurement) also exist as tabs of the
  [Operational Tracker](operational-tracker.md). See that page for which copy is live in each project.
- The packaged `CosmediSites_Redesign_Template_Pack_v1.0.docx` is attached to the GitHub Release.
  These Markdown files are the editable source.
